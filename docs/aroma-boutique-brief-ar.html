واجهة المستخدم

متطلبات العميل — Frontend Frontend

1. الصفحة الرئيسية (Homepage)

  • عرض بانر رئيسي (صور + روابط مباشرة للمنتجات المميزة).
  • قسم المنتجات المميزة من البراند الخاص.
  • قسم براندات أخرى.
  • تصنيفات حسب نوع العطر (عود – مسك – زهري – فريش – بخور منزلي).
  • آراء العملاء مع تقييمات وصور إن وجدت.

فوتر الموقع

  • روابط الصفحات (عنّا، المتجر، المدونة، التواصل).
  • روابط التواصل الاجتماعي.
  • معلومات التواصل (بريد إلكتروني / رقم الهاتف).

2. صفحة المتجر (Shop Page)

  • عرض جميع المنتجات في شبكة.

فلترة المنتجات حسب

  • البراند.
  • نوع الرائحة.
  • النوع (ذكر / أنثى).
  • السعر.

ترتيب المنتجات

  • الأحدث.
  • الأكثر مبيعًا.
  • السعر تصاعدي/تنازلي.

بطاقات المنتجات تتضمن

  • صورة المنتج.
  • الاسم والسعر.
  • زر "أضف إلى السلة".
  • شارة "حصري" إن وجدت.

3. صفحة تفاصيل المنتج (Product Details)

  • معرض صور متعددة للمنتج.
  • عرض ملاحظات العطر (علوية – وسطى – قاعدة).
  • وصف تفصيلي ومكونات المنتج.
  • إمكانية اختيار الحجم أو الكمية.
  • زر إضافة إلى السلة.
  • قسم منتجات مشابهة أسفل الصفحة.
  • أزرار مشاركة المنتج على وسائل التواصل.

4. السلة والدفع (Cart & Checkout)

  • عرض المنتجات المختارة مع الكميات والأسعار.
  • إدخال كود خصم.
  • ملخص الأسعار (المجموع – الشحن – الإجمالي).
  • صفحة دفع آمنة وسهلة الاستخدام.
  • دعم طرق دفع متعددة (Visa – MasterCard – PayPal – Apple Pay).

5. عن البراند (About Page)

  • قصة العلامة التجارية وفلسفتها.
  • تفاصيل عن جودة المكونات ومصادرها.
  • قسم تعريفي بالمؤسس مع صور/فيديو.

6. المدونة (Journal / Blog)

  • مقالات حول العطور والفخامة.
  • نصائح التنسيق والاستخدام.
  • أفكار هدايا العطور.
  • إمكانية قراءة المقال كاملًا عبر صفحة مخصصة.

7. صفحة التواصل (Contact Page)

  • نموذج تواصل مباشر (اسم – بريد – رسالة).
  • عرض بيانات الاتصال (البريد – رقم الهاتف – حسابات التواصل).
  • روابط إلى الصفحات القانونية والسياسات.

8. الصفحات القانونية (Legal Pages)

  • سياسة الشحن والاسترجاع.
  • سياسة الخصوصية.
  • الشروط والأحكام.
لوحة التحكم

متطلبات الأدمن — Backend Backend

1. إدارة المنتجات

  • إضافة / تعديل / حذف المنتجات.
  • تحديد نوع العطر، البراند، السعر، الوصف، المخزون.
  • رفع صور متعددة للمنتج.
  • تعيين منتجات مميزة / حصرية.

2. إدارة التصنيفات والبراندات

  • إضافة / تعديل / حذف التصنيفات (عود – مسك – ...).
  • إضافة / تعديل / حذف البراندات.

3. إدارة الطلبات (Orders)

  • عرض كل الطلبات مع الحالة (جديد – قيد المعالجة – مكتمل – ملغى).
  • تحديث حالة الطلب وإرسال إشعارات للعميل.
  • عرض تفاصيل الدفع والشحن.

4. إدارة العملاء

  • عرض بيانات المستخدمين المسجلين.
  • إمكانية تعديل / حظر / حذف الحسابات.
  • عرض سجل الطلبات لكل عميل.

5. إدارة الأكواد الترويجية (Coupons)

  • إنشاء أكواد خصم جديدة.
  • تحديد نوع الخصم (نسبة / مبلغ ثابت).
  • تحديد مدة الصلاحية وعدد مرات الاستخدام.

6. إدارة المدونة

  • إضافة / تعديل / حذف المقالات.
  • إدارة الصور والعناوين والمحتوى.

7. إدارة التقييمات والآراء

  • مراجعة آراء العملاء قبل النشر.
  • حذف أو تعديل التعليقات المسيئة.

8. إعدادات عامة

  • تعديل شعار الموقع – الألوان – بيانات التواصل.
  • إدارة صفحات السياسة من خلال محرر محتوى.
  • إعداد وسائل الدفع والشحن.
